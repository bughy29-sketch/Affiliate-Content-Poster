# Imagini pentru pinuri

## Pinuri eMAG / Profitshare

Imaginile **nu** se pun aici: `scripts/import_profitshare_feed.py` folosește
direct URL-ul `product_pic` din feed (CDN-ul magazinului), iar Pinterest
descarcă imaginea la publicare. Nu copia imaginile în repo.

## Pinuri Amazon

Aici punem **doar** imagini proprii sau cu licență clară (poze făcute de tine,
Canva, stock). Pozele de produs de pe Amazon **nu** sunt permise pe Pinterest.

Convenție de nume:

```
images/amazon-001.jpg
images/amazon-002.jpg
```

Recomandări:

- JPG sau PNG, orientare verticală **2:3** (ex. 1000 × 1500 px);
- fără prețuri, fără logo-uri de magazin, fără text mare suprapus;
- după push, imaginile devin publice la:
  `https://bughy29-sketch.github.io/Affiliate-Content-Poster/images/amazon-001.jpg`

GitHub Pages poate întârzia ~1 minut după push până servește fișierele noi.
